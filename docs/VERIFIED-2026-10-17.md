# Validation report — October 17, 2026

Reference system: Dell XPS 15 7590, Fedora 43 KDE/Wayland, BIOS 1.42.0, kernel `7.1.12-100.fc43.x86_64`. Tests did not reboot the machine. The optional SDDM timeout change was applied separately and its configuration checked.

## Confirmed

- PCI drivers bound: `i915`, `nvidia`, `iwlwifi`, `snd_hda_intel`, `rtsx_pci`, `thunderbolt`, and `nvme`.
- Intel accelerated OpenGL: UHD 630, Mesa 25.3.6, direct rendering enabled.
- NVIDIA API and PRIME OpenGL: GTX 1650, NVIDIA 580.178.04, OpenGL 4.6. No sustained-load test.
- Wi-Fi connected; `iwlwifi` loaded `cc-a0-77.ucode`.
- PipeWire exposed analog playback/capture endpoints and V4L2 camera devices.
- Bluetooth firmware loaded and controller powered on. No pairing test.
- fwupd detected system firmware and Thunderbolt. Firmware updates and online update availability were not checked.
- A later Goodix verification reported a successful match in the service log. This is not a controlled biometric accuracy test.

## Login timing

The initial fingerprint attempt started at 23.894 seconds after boot, timed out at 53.890 seconds, and the KDE session opened at 54.393 seconds. Sensor opening completed in under a second. A later attempt started at 246.148 seconds and matched at 250.749 seconds.

Four recorded boots showed the same 30-second verification timeout; one included two attempts. The reported three-to-four-minute continuous password check was not reproduced from these records.

The SDDM rule was changed to `pam_fprintd.so timeout=8 max-tries=1`, with an original-file backup. File verification and `authselect check` passed. A subsequent cold-boot login remains untested. See [fingerprint troubleshooting](FINGERPRINT.md).
